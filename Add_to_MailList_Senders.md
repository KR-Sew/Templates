# Добавление в список пользователей почтовых рассылок ГК "Везу.Ру"
![Win ACME Version](https://img.shields.io/badge/Win_ACME-v2.2.0-blue)  
![Let's Encrypt](https://img.shields.io/badge/Powered_by-Let's_Encrypt-brightgreen)

## Порядок действий
1. **Добавьте адрес эл.почты сотрудника**  
   - Откройте `web панель` управления почтовым сервером **MDaemon** 
   - В колонке слева в группе `Main` **Главное** выбирите пункт `Mailing lists` **Списки рассылок**  
   - В открвывшемся окне справой стороны выберите нужный **Список рассылки** и в панеле инструментов сверху списка рассылок выберите `Edit` **Редактировать**
   - В открывшемся диалоговом окне нажмите `New` **Новый/Добавить** для добавления почтового адреса (***не псевдонима*** `Not Alias`) пользователя в список пользователей рассылки.  
   - Выберите тип доступа упарвления рассылкой:
      - `Normal` **Обычный** получение сообщений от листа рассылки и отправка сообщений на список рассылки
      - `Digest` **Дайджест** участники списка рассылки будут периодически получать пакеты этих архивных сообщений списка рассылки типа `Digest` **Дайджест** в компактном и индексированном формате, а не получали их по одному.
      - `Read Only` **Только Чтение** участинки могут только получать сообщения списка рассылки.
      - `Post Only` **Только Отправка** участники группы могу только отпавлять сообщения на список рассылки.
   - Затем нажмите `Save and Close` **Сохарнить и закрыть**.

2. **Обязательные действия**  
   - Отметье только что добавленный адрес, ***кликнув*** на нём однократно.
   - В ставшей активной вверхней панели инструментов нажатием клавиш `Up` **Вверх** / `Down` **Вниз** переместите адрес выше существующей записи с типом доступа `Read Only`
   - Иначе новый добавленный адресат **НЕ СМОЖЕТ** отпавлять сообщения на этот лист рассылки
